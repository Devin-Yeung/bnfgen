# Use token-backed tolerant syntax documents

`bnfgen-syntax` will parse source text into a token-backed `ParsedDocument` that preserves the original input and returns useful structure even when the grammar is incomplete. Parsing is total: every input returns a document, with syntax errors stored inside it rather than returned as a failed parse. LALRPOP consumes a significant-token view, while the document retains raw tokens, trivia, invalid input, recovered regions, and syntax errors. Recognized structure is exposed through language-specific immutable syntax views over private token-and-range-backed records, rather than through a generic concrete syntax tree or a partial generation AST.

## Consequences

Parsing an incomplete rule must not discard later valid rules or unrecognized source text. The complete token buffer is the source-preserving representation: tokens retain kinds and UTF-8 byte ranges into the original source instead of copied or decoded values. Private syntax and recovery records refer to tokens or ranges, so trivia and unexpected input never need to be reinserted into a second tree. Typed accessors return `None` where incomplete syntax omits a required child. Storage and recovery internals remain private behind immutable syntax views. Syntax parsing does not decode values, compile regular expressions, resolve names, or establish generation invariants; those operations belong to downstream lowering and analysis. This costs more than a fail-fast typed AST, but prevents diagnostics and the future language server from requiring another foundational parser redesign.
